# Black Jack

Welcome to my Black Jack game!

## How to Play
- **Run the game:** Double-click `BlackJackGame.exe` to start.
- **Controls:** Use your mouse to interact with the buttons on the screen (Hit, Stand, Double Down, Split).
- **Objective:** Beat the dealer without going over 21.

## Feedback
I am currently playtesting this version. If you run into any bugs, glitches, or crashes, please let me know! 

Enjoy the game!
